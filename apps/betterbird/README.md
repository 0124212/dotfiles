# betterbird

Betterbird email client — Dracula-inspired dark theme + rice configs.

## Install

```powershell
.\install.ps1
```

## What's Included

| File | What it does |
|------|-------------|
| `chrome/userChrome.css` | Dracula dark theme for UI |
| `chrome/userContent.css` | Dark theme for message body |
| `user.js` | Font, compose, and privacy settings |

## Theme

Dracula-inspired color palette:
- Background: `#282A36`
- Foreground: `#F8F8F2`
- Accent: `#BD93F9` (purple)
- Muted: `#6272A4`
- Border: `#44475A`

## Manual Steps

1. Launch Betterbird once to create profile
2. Run `install.ps1` again if theme doesn't apply
3. Restart Betterbird
