# thicc-zebar — 55px gruvvy-watermelon Zebar bar

Private fork of [zacccharv/bar-gruvvy-watermelon](https://github.com/zacccharv/zebar-gruvvy-watermelon) (itself a Gruvvy Watermelon / rose-pine fork) — the thicc variant for GlazeWM.

## Details

- **Height:** `55px` thicc bar, `top_center`, 100% width
- **Theme:** Gruvvy Watermelon (rose-pine palette)
- **WM:** GlazeWM workspaces
- **Widget:** renamed to `thicc-bar` for personal use

## Preview

`assets/example_0.png` — 55px bar in situ

## Install

```powershell
git clone https://github.com/0124212/thicc-zebar $env:USERPROFILE\.glzr\zebar\thicc-zebar
# or copy to %USERPROFILE%\.glzr\zebar\thicc-zebar
# enable in Zebar marketplace (private)
```
